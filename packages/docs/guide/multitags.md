# Multitags 多行标签

「标题 + 标签组」两行展示，`value` 传 `标题(项1、项2、项3)` 格式字符串，括号内以 `、`/`,`/`，` 分割为标签；无括号时整体作为标题、不展示标签。

标签行超出容器宽度时省略号截断（每个标签最大 120px，超出内部省略）。

配合 `dart-table-column` 的 `useType="multitags"` 使用时，`useArg` 支持字符串与数组两种格式（见 [Table 文档](/guide/table#多行标签列)）。
