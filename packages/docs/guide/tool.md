# Tool 工具栏（新）

配合表格使用的工具栏组件，左侧为内容区，右侧为操作区，并内置全屏、列竖线、表格设置三个默认按钮，常与 `dart-table` 组合使用。

## 基本用法

内置按钮通过事件交由外部控制：全屏/竖线按钮点击后回传当前状态，表格设置按钮仅通知外部打开设置面板。

<demo src="tool/d1" />

## 自定义按钮显示

通过 `show-full-screen`、`show-border`、`show-columnset` 控制默认按钮的显示，操作区插槽可放置任意按钮。

<demo src="tool/d2" />

## 属性

| 参数             | 说明                 | 类型     | 可选值 | 默认值  |
| ---------------- | -------------------- | -------- | ------ | ------- |
| span             | PC 端屏幕分栏占比    | number[] | -      | [12,12] |
| span-xs          | 移动端小屏幕分栏占比 | number[] | -      | [24,24] |
| show-default-btn | 显示默认操作按钮（全屏/竖线/表格设置，隐藏时含分隔竖线） | boolean | - | true |
| show-full-screen | 显示表格全屏按钮     | boolean  | -      | false   |
| show-border      | 显示列竖线按钮       | boolean  | -      | true    |
| show-columnset   | 显示表格设置按钮     | boolean  | -      | true    |

## 事件

| 事件名            | 说明                   | 回调参数       |
| ----------------- | ---------------------- | -------------- |
| fullscreen-change | 全屏按钮切换时触发     | (val: boolean) |
| border-change     | 竖线按钮切换时触发     | (val: boolean) |
| columnset         | 表格设置按钮点击时触发 | -              |

## 插槽 slot

| 参数    | 说明                                           |
| ------- | ---------------------------------------------- |
| content | 左侧功能区                                     |
| operate | 右侧的操作区，可添加其他比如按钮等组件进行组合 |
