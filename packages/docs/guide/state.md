# State 状态展示

用于表格、列表等场景展示状态：前方为圆点，后方为文案；颜色类型与 Element Plus `el-tag` 的 `type` 一致（使用主题色变量）。

## 基础

<demo src="state/d1" />

## 属性

| 参数    | 说明                               | 类型   | 可选值                                      | 默认值 |
| ------- | ---------------------------------- | ------ | ------------------------------------------- | ------ |
| type    | 状态类型，与 `el-tag` 的 type 对应 | string | primary / success / info / warning / danger | info   |
| text    | 无默认插槽时的展示文案             | string | —                                           | ''     |
| dotSize | 圆点直径（px）                     | number | —                                           | 6      |

## 插槽

| name    | 说明                      |
| ------- | ------------------------- |
| default | 自定义文案（优先于 text） |

字体大小继承父级（如表格单元格），便于与表格排版一致。
